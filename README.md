WHAT IF?
Educational & Career Decision Simulation Platform

WHAT IF? is a web-based platform designed to help users explore educational courses, understand possible career paths, identify required skills, and make informed career decisions.

Features

- User registration and login
- Secure password hashing
- JWT-based authentication
- User profile management
- Course management
- Course CRUD APIs
- MongoDB database integration
- RESTful backend APIs
